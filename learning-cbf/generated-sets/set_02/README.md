# set_02 — maze world CBF training data

Generated by `learning-cbf/build_maze_sets.py` from
`maze_env/results/maze_sim.csv` (5,000 simulated expert trajectories,
A* + pure-pursuit + RK4, dt = 0.1 s, robot radius 0.1 m).
Maze geometry: `maze_env/maze_config.py::sketch_maze()`.

## Files

| File | Rows | Columns | Meaning |
|---|---|---|---|
| `X_safe.csv` | 386,649 | `x,y,theta,v,omega` | Expert states. Wall distance ≥ 0.126 m. Same schema as set_01. |
| `N.csv` | 50,000 | `x,y,theta,v,omega` | **Sampled true collision states** (wall distance < 0.10 m = robot radius). 60% uniform over the collision region (incl. wall interiors and outside the borders), 40% in the band [0.07, 0.10) to pin the boundary. `theta` ~ U(−π, π); `(v, omega)` pairs are bootstrap-resampled jointly from the safe set, so the control distribution is *identical* in both classes and carries zero label information. |
| `transitions.csv` | 381,649 | `x,y,theta,v,omega,x_next,y_next,theta_next,dt` | Exact RK4 transitions (consecutive sim steps within each trajectory; verified against `model.py` dynamics to 1e-6). For the discrete invariance loss. |

## Label semantics

```
unsafe   d(x) <  0.10 m         (true collision: robot disc overlaps a wall)
buffer   0.10 m ≤ d(x) < 0.126  UNLABELED — no training signal here;
                                 the zero level set h=0 should end up in
                                 this gap, shaped by the invariance loss
safe     d(x) ≥ 0.126 m         (every expert state satisfies this)
```

Unlike set_01 (circle world), `N` is **not** relabeled near-obstacle expert
data — every row is genuinely infeasible. The two sets are disjoint with a
deliberate margin between them.

## Intended losses

1. Safe margin:        `h(x) ≥ γ` for x in X_safe
2. Unsafe margin:      `h(x) ≤ −γ` for x in N
3. Discrete invariance (this is what makes h a CBF, not a classifier):
   `h(x_next) ≥ (1 − α·dt)·h(x)` for rows of transitions.csv

Recommended model input: **`(x, y)` only.** The robot footprint is
circular and the maze is static, so collision geometry depends on
position alone; heading affects the dynamics but not the safe set.
`theta, v, omega` stay in the CSVs for the invariance term and the
downstream QP (`grad_h(x) . f(x, u)`), not as inputs to h.
